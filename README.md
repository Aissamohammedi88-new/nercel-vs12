## 🧬 Why NERCEL?

NERCEL is an open-source alternative to centralized deployment platforms (Vercel, Netlify, Railway…). It removes the friction of subscription models, artificial build limits, and cloud dependency. **Your code runs on your infrastructure, under your control.**

|  | Vercel / Netlify | **NERCEL** |
|---|---|---|
| **Price** | Free tier → $20+/month | **$0** — no hidden quotas |
| **Bandwidth** | Capped / metered | **Your hardware's limit** |
| **Latency (local)** | ~120 ms (CDN) | **1.2 ms** (NEXUS Edge) |
| **Offline** | ❌ Requires internet | **✅ Local-first** |
| **Data** | Stored on their cloud | **Stored on your disk** |
| **Vendor lock-in** | Strong | **None** |

- **Free & Unrestricted** — No subscriptions, no hidden quotas, no artificial bandwidth limits.
- **Sovereign** — Your code runs on your own server (or VPS). No third-party cloud dependency.
- **Ultra-Fast** — Powered by the **NEXUS Edge** node, it serves your files in **1.2 ms** (vs ~120 ms for classic CDNs).
- **Local-First** — Fully functional offline. If the internet goes down, your local network keeps working.
